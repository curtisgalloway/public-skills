# ARM PrimeCell PL011 UART

## Orientation

The PL011 is ARM's licensable UART, found on-SoC in Broadcom's BCM2711 and BCM2712, inside the RP1
southbridge, and across many other ARM SoCs. It has a public TRM, so every register-level fact about
it is citable without reading any driver. An SoC places one or more instances at addresses of its
choosing; those placements, their interrupts, and their clocks are instance facts and live in the
SoC's or chip's `instances:` table, not here.

## Standards and databook

- The register map, FIFO depths, and programming sequences are defined by the PL011 TRM. `[databook]`
  (DDI 0183)
- Framing, baud generation, and the modem-control lines follow the conventional asynchronous serial
  model; there is no separate standard to cite beyond the TRM. `[databook]` (DDI 0183)
- The devicetree binding fixes the `compatible` pair `arm,pl011` / `arm,primecell` and the two
  clocks an instance provides, `uartclk` and `apb_pclk`. `[standard]` (pl011.yaml binding)

## Programming model

- **Register organization.** Data, receive-status/error-clear, flag, IrDA low-power, integer and
  fractional baud divisors, line control, control, interrupt FIFO level select, interrupt mask,
  raw and masked interrupt status, interrupt clear, DMA control, then the PrimeCell peripheral and
  cell identification registers at the top of the 4 KiB window. Offsets and bit positions: cite the
  TRM's register summary. `[databook]` (DDI 0183, register summary)
- **Enable sequence.** Disable the UART; wait for the current transmission to finish (busy flag
  clear); flush the transmit FIFO by disabling FIFOs in line control; program the baud divisors from
  the reference clock; program line control (word length, FIFO enable, parity, stop bits) last among
  the divisor registers, because the divisor write is latched by the line-control write; enable
  transmit, receive, and the UART in the control register. `[databook]` (DDI 0183, programming the
  control registers)
- **Baud.** Divisor = reference clock / (16 × baud); the integer part goes in the integer divisor
  register and the fractional part, scaled to 6 bits, in the fractional divisor register. The
  reference clock is an instance fact. `[databook]` (DDI 0183, fractional baud rate divider)
- **Transmit readiness.** Poll the flag register: the transmit-FIFO-full flag clear means a byte may
  be written; the busy flag clear means the transmitter has drained. `[databook]` (DDI 0183, flag
  register)
- **Interrupts.** One combined interrupt line, with per-source enables in the mask register and
  per-source clears in the interrupt-clear register; receive, transmit, receive-timeout, and the
  error and modem-status sources. FIFO trigger levels are selectable. `[databook]` (DDI 0183,
  interrupts)
- **DMA.** Separate transmit and receive DMA request lines, enabled in the DMA control register;
  single and burst requests derived from the FIFO levels. `[databook]` (DDI 0183, DMA interface)

## Known variants and quirks

- The 16-entry FIFOs are the TRM's configuration; some integrations expose deeper FIFOs while
  keeping the register interface. Treat FIFO depth as an instance fact when it matters.
  `[databook]` (DDI 0183). `TODO (verify on hardware)`: the instance depth, per SoC.
- Register access width: instances are commonly wired for 32-bit accesses to 4-byte-aligned
  registers even though the registers are 16 bits or narrower; a devicetree instance may state
  `reg-io-width`. `[standard]` (pl011.yaml binding)
- The primary and secondary configuration of the modem-control lines varies by integration; an SoC
  that wires only TX and RX leaves the flags for CTS/DSR/DCD/RI unconnected. `[databook]` (DDI 0183)

## Gotchas

- Writing the divisor registers without a following line-control write leaves the old divisor in
  effect; the line-control write is what latches them. `[databook]` (DDI 0183)
- Enabling the UART before the baud and line control are programmed produces garbage on the line
  during the reprogramming window; disable first. `[databook]` (DDI 0183)
- The receive-timeout interrupt fires only when the receive FIFO is non-empty and idle for a
  character period; a poll-only driver that clears the FIFO never sees it. `[databook]` (DDI 0183)
