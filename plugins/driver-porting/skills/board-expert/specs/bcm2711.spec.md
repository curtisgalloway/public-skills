# Broadcom BCM2711

## Orientation

The BCM2711 is the Raspberry Pi 4 / Pi 400 / Compute Module 4 application processor: four
Cortex-A72 cores in one cluster, with the VideoCore VI VPU co-running the firmware that owns boot,
most clocks, and power. There is no southbridge: Ethernet (GENET v5), GPIO, UARTs, and SD are on-SoC,
and the PCIe root complex hosts a single device. Peripherals documented at legacy bus `0x7Ennnnnn`
appear to the ARM at `0xFEnnnnnn` in the default low-peripheral mode. The **BCM2711 ARM Peripherals
datasheet is public**: cite it as the authority and use the kernel and device tree as the map.

## Quick-facts

- **Addressing model.** Default is **low-peripheral mode**: main peripherals (legacy bus
  `0x7C00_0000`–`0x7FFF_FFFF`) appear to the ARM at `0xFC00_0000`–`0xFF7F_FFFF`; ARM-local
  peripherals and the GIC at `0xFF80_0000`–`0xFFFF_FFFF`. Rule: datasheet legacy `0x7Enn_nnnn` → ARM
  `0xFEnn_nnnn` (and `0x4_7Enn_nnnn` in the full 35-bit map). The `scb` bus (GENET, PCIe RC) maps
  `0x7D5n_nnnn` → `0xFD5n_nnnn`. RAM starts at physical 0; the VPU's `gpu_mem` share is carved from
  the top of the first 1 GiB. `arm_peri_high=1` switches to high-peripheral mode (needs a matching
  DT and armstub). Worked example: PL011 UART0 = legacy `0x7E20_1000` → ARM **`0xFE20_1000`**,
  matching the official `earlycon=pl011,mmio32,0xfe201000`. `[databook]` (BCM2711 datasheet §1.2),
  `[DT]` (`bcm2711.dtsi` `ranges`)
- **DMA windows and caps.** Legacy masters reach RAM only through a 1 GiB window at bus
  `0xC000_0000` (so ZONE_DMA = 1 GiB); the `scb` masters (GENET) see RAM 1:1 with no limit; PCIe
  inbound is capped at **3 GiB**; the `emmc2bus` `dma-ranges` are **patched by firmware per SoC
  stepping**. `[databook]` (BCM2711 datasheet §1.2, ch. 4), `[DT]` (`dma-ranges`), `[doc]`
  (Raspberry Pi documentation for the firmware patching)
- **Boot chain and entry state.** BootROM → SPI-EEPROM bootloader → `start4.elf` (VPU) loads the
  DTB, the armstub (at physical 0), and the kernel, patches the DTB, and releases the ARM cores into
  the stub at **EL3**. The stock stub sets `CNTFRQ_EL0` = 54 MHz and `SCR_EL3` = {NS=1, RW=1, HCE=1,
  **SMD=1: SMC disabled, no EL3 runtime**}, then ERETs to the kernel at **EL2, AArch64, MMU off,
  caches off, DAIF masked, x0 = DTB physical address**, x1–x3 = 0 (the arm64 `booting.rst`
  contract). The 64-bit kernel loads at `0x20_0000` on current firmware (older: `0x8_0000`); the
  firmware honors the Image header `text_offset`, so do not hard-code it. `[doc]` (Raspberry Pi
  documentation, boot flow), `[standard]` (Linux arm64 `booting.rst`), `[source-observed]`
  (`armstub8.S` for the SCR_EL3 and CNTFRQ programming) `TODO (verify on hardware)`
- **Stub patch points.** The firmware patches the stub's DTB-pointer word at stub offset `0xF8` and
  the entry word at `0xFC` (stub magic `0x5AFE570B` at `0xF0`). `[source-observed]` (`armstub8.S`)
  `TODO (verify on hardware)`
- **Secondary-core release: spin-table.** Cores 1–3 WFE-poll 64-bit release words at physical
  **`0xD8` / `0xE0` / `0xE8` / `0xF0`** (= DT `cpu-release-addr`); write the entry address, barrier,
  SEV; a secondary enters at EL2, MMU and caches off, x0 = 0. `[DT]` (`cpu-release-addr` in
  `bcm2711.dtsi`), `[standard]` (`booting.rst` spin-table protocol), `[source-observed]`
  (`armstub8.S`) `TODO (verify on hardware)`
- **PSCI only with TF-A.** Build `PLAT=rpi4` and ship `armstub=bl31.bin`: BL31 resides at
  `0x1000`–`0x8_0000` (keep the low 512 KiB clear) and adds the PSCI and reserved-memory nodes to
  the live DTB. `[doc]` (TF-A rpi4 platform page), `[standard]` (PSCI DEN 0022)
- **SMP topology.** 4 × Cortex-A72, one cluster; cpu DT `reg` = 0–3 = **MPIDR Aff0** (Aff1 = Aff2 =
  0, unlike the Pi 5 where the core index is in Aff1). Boot core 0. L1D 32 KiB, L1I 48 KiB, shared
  L2 1 MiB. `[DT]` (cpu nodes in `bcm2711.dtsi`), `[databook]` (Cortex-A72 TRM for the caches)
- **Interrupts.** **GIC-400 (GICv2)**, 192 SPIs: GICD **`0xFF84_1000`**, GICC **`0xFF84_2000`**
  (GICC_DIR at +0x1000), GICH `0xFF84_4000`, GICV `0xFF84_6000`. DT `#interrupt-cells = 3`
  ⟨type, n, flags⟩: SPI INTID = n + 32, PPI INTID = n + 16. Allocation: VideoCore IRQ *v* → DT SPI
  **64 + v** (e.g. VC 57 = all PL011s → SPI 121; VC 62 = both SDHCIs → SPI 126); ETH_PCIe block L2
  IRQ *i* → DT SPI **128 + i** (GENET = 157/158); ARMC IRQs at SPI 32–47 (VPU mailbox = 33). The
  legacy ARMC controller still exists at `0xFE00_B000` and takes over when `enable_gic=0` (the Pi 4
  default is 1). `[databook]` (BCM2711 datasheet ch. 6), `[DT]` (gic node), `[standard]` (GICv2
  IHI 0048, GIC-400 TRM DDI 0471)
- **Debug UART.** PL011 **UART0 at `0xFE20_1000`**, DT GIC_SPI **121** (level-high, the shared OR of
  all five PL011s at `0x7E201000/400/600/800/a00`), 32-deep FIFOs (AMBA periphid `0x00341011`),
  **UARTCLK = 48 MHz** (firmware `init_uart_clock`), default 115200 baud.
  `earlycon=pl011,mmio32,0xfe201000`. Pinmux: GPIO 14/15 **ALT0** = TXD0/RXD0. Register model per
  the PL011 TRM (see the `pl011` IP spec); the header-console trap is a board fact (see `rpi4`).
  `[databook]` (BCM2711 datasheet ch. 11; DDI 0183), `[DT]` (`bcm2711.dtsi` uart0 node), `[doc]`
  (Raspberry Pi documentation for `init_uart_clock` and earlycon)
- **Timers.** ARM generic timer at **54 MHz** (stub-programmed; read `CNTFRQ_EL0`, do not
  hard-code). Timer PPIs ⟨GIC_PPI n → INTID⟩: secure-phys 13 → 29, nonsecure-phys 14 → 30, virt 11
  → 27, hyp 10 → 26, all level-low. BCM **system timer** at `0xFE00_3000`: 64-bit 1 MHz free-running
  counter, four compare channels → DT SPI 64–67; channels 0/2 conventionally VPU-owned, use 1/3:
  `TODO (verify on hardware)`. `[DT]` (timer nodes), `[standard]` (ARMv8-A ARM generic timer),
  `[databook]` (BCM2711 datasheet ch. 10)
- **Clocks and power.** Split ownership. The **VPU firmware mailbox** (property channel 8, registers
  at **`0xFE00_B880`**, IRQ DT SPI 33) owns clock rates, voltages, power domains, and the firmware
  GPIO expander. **CPRMAN** at **`0xFE10_1000`** (`brcm,bcm2711-cprman`) is OS-programmed for
  peripheral clocks (EMMC2, PWM, GP clocks; one shared PL011 clock). Bring-up costs: UART0, none
  (48 MHz already running); EMMC2, the CPRMAN EMMC2 clock plus firmware-expander voltage switching;
  GENET, **nothing** (no clock handle; always on). `[DT]` (`bcm2711.dtsi` mailbox, cprman, and clock
  handles), `[doc]` (mailbox property interface wiki), `[source-observed]` (bring-up costs as the
  drivers exercise them) `TODO (verify on hardware)`
- **GPIO and pinmux.** Single block at **`0xFE20_0000`**, **58 GPIOs**. GPFSEL0–5 at `0x00`–`0x14`,
  3 bits per pin (000 in, 001 out, 100/101/110/111 = ALT0–3, 011 = ALT4, 010 = ALT5). GPSET / GPCLR
  / GPLEV pairs at `0x1C` / `0x28` / `0x34`; event and edge registers `0x40`–`0x8C`. **Pulls are
  BCM2711-specific:** GPIO_PUP_PDN_CNTRL_REG0–3 at **`0xE4` / `0xE8` / `0xEC` / `0xF0`**, 2 bits per
  GPIO (00 none, **01 up, 10 down**), 16 GPIOs per register; the BCM2835 GPPUD/GPPUDCLK dance does
  nothing on the 2711. Map at least `0xF4` (the classic DT size `0xB4` misses the pull registers).
  Bank IRQs DT SPI 113–116. `[databook]` (BCM2711 datasheet ch. 5), `[DT]` (gpio node)
- **DTB runtime patching.** `start4.elf` fills `/memory@0` (a placeholder in the source DT),
  assembles `/chosen/bootargs`, patches the **`emmc2bus` `dma-ranges` per SoC stepping**, writes the
  GENET MAC address (via the `ethernet0` alias), places the `blconfig` / `blpubkey` reserved-memory
  nodes, and merges `dtoverlay=` overlays; TF-A adds the PSCI node. **Parse the live DTB passed in
  x0**: the static `.dts` is a template, not the contract. `[doc]` (Raspberry Pi documentation; TF-A
  rpi4 platform page), `[DT]` (the placeholders in the source DT)
- **Key peripheral identities.** GPIO: `brcm,bcm2711-gpio` @ `0xFE20_0000`, SPI 113–116. Ethernet:
  GENET v5, `brcm,bcm2711-genet-v5` @ **`0xFD58_0000`** (64 KiB, `scb` bus), SPI **157/158**,
  internal MDIO at **+0xE14** (`brcm,genet-mdio-v5`). SD: **EMMC2** `brcm,bcm2711-emmc2`
  (SDHCI-class) @ **`0xFE34_0000`**, SPI **126**; the Arasan SDHCI @ `0xFE30_0000` (also SPI 126);
  `sdhost` @ `0xFE20_2000`, SPI 120. PCIe RC: `brcm,bcm2711-pcie` @ `0xFD50_0000`, outbound CPU
  `0x6_0000_0000` (64 MiB), inbound capped at 3 GiB. Which slot each SD controller serves is a
  board fact (see `rpi4`). `[DT]` (`bcm2711.dtsi`), `[standard]` (SD Host Controller spec for the
  SDHCI-class controllers; IEEE 802.3 for GENET's MDIO)

## Gotchas

- **BCM2711 changed pull-resistor programming silicon-wide.** Use GPIO_PUP_PDN_CNTRL_REG0–3
  (`0xE4`–`0xF0`, 01 = up, 10 = down); BCM2835-style GPPUD/GPPUDCLK code silently no-ops, and a
  `0xB4`-sized MMIO mapping does not even cover the new registers. `[databook]` (BCM2711 datasheet
  ch. 5)
- **PCIe inbound DMA caps at 3 GiB** (a wrapper limitation): USB DMA buffers must sit below 3 GiB on
  4 / 8 GiB boards. Legacy-master DMA caps at 1 GiB (the bus `0xC000_0000` window); EMMC2's reach is
  whatever the **firmware-patched** live `emmc2bus` `dma-ranges` say. `[DT]` (`dma-ranges`),
  `[databook]` (BCM2711 datasheet §1.2)
- **The stock armstub is spin-table with no EL3 runtime: SMC is disabled** (`SCR_EL3.SMD`) and
  faults as undefined. PSCI requires shipping TF-A BL31 as `armstub=` (it then owns
  `0x1000`–`0x8_0000`). `[source-observed]` (`armstub8.S`) `TODO (verify on hardware)`, `[doc]`
  (TF-A rpi4 platform page)
- **Interrupt lines are shared pervasively:** one SPI for all five PL011s (121), one for both SDHCI
  controllers (126), one for SPI3–6 (118), one for I2C3–6 (117); demux via per-block status
  registers. `[DT]` (`bcm2711.dtsi`), `[databook]` (BCM2711 datasheet ch. 6)
- **Low- vs high-peripheral mode must be consistent** across firmware, DT, and armstub; everything
  stock assumes low (`0xFE...`). `[databook]` (BCM2711 datasheet §1.2), `[doc]` (Raspberry Pi
  documentation, config.txt)
- **Do not look for peripherals at `0x10_0000_0000` or on an RP1.** That is the Pi 5 (BCM2712);
  everything here is on-SoC at `0xFE...` / `0xFD...`. `[DT]`
