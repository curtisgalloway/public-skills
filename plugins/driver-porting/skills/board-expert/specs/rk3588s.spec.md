# Rockchip RK3588S / RK3588

## Orientation

The RK3588S is an octa-core DynamIQ SoC: 4× Cortex-A76 (big) + 4× Cortex-A55 (little), a Mali-G610
GPU, an 8K VPU, and a roughly 6-TOPS NPU. The RK3588 is the fuller variant with extra peripherals
(`rk3588.dtsi`); the facts below are generic to both and apply to most RK3588(S) boards (Radxa ROCK 5,
Orange Pi 5, Indiedroid Nova, …). Addressing is flat with no high window and no companion I/O chip,
the boot chain ends in TF-A BL31, the interrupt controller is a GIC-600 (GICv3), the debug UART is a
DesignWare 8250 (see the `dw-apb-uart` IP spec), and clocks are OS-managed through the CRU with
CPU/GPU/NPU DVFS served by BL31 over SCMI. The RK3588 TRM is Rockchip-copyright but community-mirrored
and is the citation of record.

## Quick-facts

- **Addressing model.** Flat/direct: no high window, no southbridge. The root node is
  `#address-cells = 2` / `#size-cells = 2`, but peripheral `reg` entries are
  `<0x0 ADDR 0x0 SIZE>`, so the physical address is the literal value (UART2 = `0xFEB5_0000`).
  On-SoC peripherals sit in `0xFD00_0000`–`0xFEFF_FFFF`; DRAM starts at `0x0`. There is no
  `0x10_0000_0000`-style offset and no off-SoC I/O chip: USB, GbE, PCIe, eMMC, and GPIO are all on
  the SoC. Still check any sub-bus that declares its own `ranges` (the PCIe controllers, the GIC
  node). `[DT]` (`rk3588-base.dtsi`)
- **Boot chain and entry state.** BootROM → DDR-init + TPL/SPL (Rockchip DDR blob from `rkbin`) →
  **TF-A BL31** at EL3 (installs PSCI-over-SMC and an **SCMI-over-SMC** server) → U-Boot (BL33) →
  kernel, entered **AArch64, EL2, MMU off, D-cache off, DTB pointer in `x0`** (the standard arm64
  boot protocol). Secondary cores start via **PSCI `CPU_ON`** (`method = "smc"`, every CPU
  `enable-method = "psci"`); no spin-table. `[doc]` (TF-A `plat/rockchip/rk3588`; rkbin),
  `[standard]` (arm64 `booting.rst`; PSCI DEN 0022), `[DT]` (psci and cpu nodes)
- **SMP topology.** Eight cores, big.LITTLE DynamIQ: CPU0–3 = Cortex-**A55** (cluster 0); CPU4–7 =
  Cortex-**A76** (clusters 1–2). DT cpu `reg` = `0x0, 0x100, …, 0x700` → MPIDR **Aff1 = 0..7,
  Aff0 = 0** (core N → `MPIDR = N << 8`); pass that as the PSCI target. The boot core is normally an
  A55 (CPU0). `[DT]` (cpu nodes in `rk3588s.dtsi` / `rk3588-base.dtsi`)
- **Interrupts.** **GIC-600 = GICv3, not GICv2.** GICD `0xFE60_0000` (size `0x10000`); GICR
  redistributors at `0xFE68_0000` (`0x100000` = 8 × `0x20000`); two ITS for MSI at `0xFE64_0000` and
  `0xFE66_0000`; MBI alias `0xFE61_0000` (`mbi-ranges <424 56>`). **`#interrupt-cells = 4`** (type,
  number, flags, PPI partition / affinity). SPI n → INTID `32 + n`; PPI n → INTID `16 + n`. GICv3
  means the CPU interface is via **system registers (`ICC_*_EL1`)**, each core must wake its
  **redistributor** (clear `GICR_WAKER.ProcessorSleep`, enable SGIs/PPIs in `GICR_ISENABLER0`), and
  SPIs use **affinity routing**: a larger, different init than a GICv2 MMIO CPU interface. Do not
  reuse a GICv2 driver. `[DT]` (gic node in `rk3588-base.dtsi`), `[standard]` (GICv3 IHI 0069)
- **Debug UART.** DesignWare 8250 (`snps,dw-apb-uart`), **not a PL011**: **UART2 at `0xFEB5_0000`**,
  IRQ SPI 333 (INTID 365), **`reg-shift = 2`, `reg-io-width = 4`** → 16550 register *indices* at a
  32-bit stride accessed as mmio32 (LSR, index 5, at byte offset `0x14`; THR/RBR at `0x00`).
  `earlycon=uart8250,mmio32,0xfeb50000`. Polled TX: wait for **LSR.THRE (bit 5)**, write **THR
  (index 0)**. The pins need IOMUX through the GRF/pinctrl; the SoC base default pin group is
  `uart2m1_xfer` and a board may override it (the Indiedroid Nova uses `uart2m0_xfer`). U-Boot
  normally muxes them already; a from-reset bare-metal path must set the GRF IOMUX or the line
  stays silent. Register model and the DesignWare "busy" quirk (an `LCR` write mid-transfer is
  ignored: reconfigure only when idle or after the DW soft reset / `USR` read): see `dw-apb-uart`.
  `[DT]` (uart2 node and pinctrl groups), `[standard]` (16550 register model), `[databook]`
  (DW_apb_uart databook, for the busy quirk)
- **Timers.** ARM generic timer at **24 MHz, not 54 MHz** (`arm,armv8-timer`), PPIs 13/14/11/10/12 =
  secure-phys / phys / virt / hyp-phys / hyp-virt. The frequency comes from the `xin24m` crystal, so
  `CNTFRQ_EL0 = 24,000,000` (read it, don't hard-code). At EL2 use `CNTHP_*` (PPI 10 → INTID 26).
  On-SoC Rockchip timers also exist (`timer@feae0000`); the architected timer is preferred. `[DT]`
  (timer nodes), `[standard]` (ARMv8-A ARM, generic timer)
- **Clocks and power.** **OS-managed**, unlike the Raspberry Pi's firmware-owned clocks. The on-SoC
  **CRU** (clock and reset unit), `clock-controller@fd7c0000` (`rockchip,rk3588-cru`), programs most
  peripheral clocks and resets directly: bringing a peripheral up usually means **ungating its CRU
  clock and deasserting its CRU reset** first. **CPU/GPU/NPU DVFS** clocks and a few resets go
  through **SCMI over SMC** (`arm,scmi-smc`, `arm,smc-id = 0x82000010`; clock protocol `0x14`, reset
  protocol `0x16`), served by BL31. The SCMI shared memory is at about `0x10F000`. Board **voltage
  rails** come from an external **RK806-class PMIC** over I²C/SPI. `[DT]` (cru, scmi, and scmi shmem nodes, protocol sub-nodes), `[standard]` (SCMI DEN 0056),
  `[source-observed]` (the shared-memory address). `TODO (verify on hardware)`: the shared-memory
  address.
- **GPIO and pinmux.** Five banks of 32 pins: `gpio0@fd8a0000`, `gpio1@fec20000`, `gpio2@fec30000`,
  `gpio3@fec40000`, `gpio4@fec50000`. IOMUX, drive, and pull are set through the **GRF** syscons
  (`sys_grf@fd58c000`, PMU GRFs at `fd58a000`, plus per-PHY and VO GRFs) and
  `rockchip,rk3588-pinctrl`. `[DT]` (gpio and grf nodes, `rk3588-pinctrl.dtsi`), `[databook]`
  (RK3588 TRM, GRF chapter, for the register detail)
- **DTB runtime patching.** U-Boot fills `/memory` with the real DRAM size and may set `/chosen`
  bootargs and fix up MAC addresses. Parse the live DTB for memory extents rather than trusting the
  static values. `[doc]` (U-Boot fdt fixups)

## Gotchas

- **GICv3, not GICv2**: system-register CPU interface, per-core redistributor wake, affinity routing,
  and DT IRQ cells = 4. A GICv2 (GICC MMIO) driver will not work. `[DT]` (`rk3588-base.dtsi`, gic
  node), `[standard]` (IHI 0069)
- **Console is a DW 8250, not a PL011**: 16550-style registers, `reg-shift = 2`, mmio32, 1.5 Mbaud
  on the Nova. PL011 offsets (FR/DR/…) do not apply; use THR/RBR/LSR/LCR/IER/FCR at index × 4. `[DT]`
  (`rk3588-base.dtsi`, `uart2`), `[standard]` (16550 register model)
- **Program the CRU yourself.** Peripherals often need their CRU gate ungated and CRU reset
  deasserted before they respond; no GPU firmware does this for you as on the Pi. `[DT]`
  (`rk3588-base.dtsi`, `cru` node), `[databook]` (RK3588 TRM, CRU chapter)
- **SCMI-over-SMC for CPU DVFS** is firmware-served (BL31): do not expect a self-contained CPU PLL
  programming path in the OS for the big/little clocks; voltages are the PMIC's job. `[DT]`
  (`rk3588-base.dtsi`, `scmi` node), `[doc]` (TF-A rk3588 platform)
- **UART2 IOMUX** must be set through the GRF if you start truly from reset; otherwise silence despite
  a correct base address. Confirm the exact pins and registers in the TRM GRF chapter and the RK3588S
  pinctrl DT. `[DT]` (`rk3588-pinctrl.dtsi`), `[databook]` (RK3588 TRM, GRF chapter)
- **You need rkbin (DDR init + BL31) or a self-built TF-A** to produce a bootable image; the
  BootROM → SPL → BL31 → BL33 chain is mandatory and Rockchip-specific. `[doc]` (rkbin repository README; TF-A Rockchip
  platform page)
- **24 MHz arch timer** (read `CNTFRQ_EL0`), and you enter at **EL2**: use `*_EL2` registers and verify
  `CurrentEL`. `[DT]` (`rk3588-base.dtsi`, timer node), `[standard]` (ARMv8-A ARM)
