The user confirmed on 2026-09-20 that the modules arrived and proposed Raspberry Pi. A bounded
board-expert subagent used the Raspberry Pi 4 stub, board-expert and os-investigator procedures
to inspect the exact upstream pin and official vendor documentation. No repository edits,

The user subsequently selected Raspberry Pi 4 Model B: "Use Pi 4 Model B."
The proposed build architecture is arm64; hardware revision and qualification remain pending. At Linux
`adc218676eef25575469234709c2d87185ca223a`, Pi 4 has board, SPI0 and GPIO interrupt support.
Its SPI node defaults disabled and needs an explicit fixture description. Pi 5's board/SoC

feasibility, not proof that the selected image builds, boots, or drives a wired module.

Pi-side SPI0 connections are documented, but no wiring instruction is issued here: module power,
pinout, IRQ routing, actual board revision and B7 evidence remain B01/B05. The public board specs
used to orient the investigation have no verification records; the exact upstream evidence above
governs this recommendation. No vendor kernel is substituted for the frozen upstream pin.

This is the final ad hoc byte/link audit, normalized to accept private roots as arguments;
it is verification evidence, not a new execution runner:

```sh
python3 - '<private-run-root>' '<retrieved-linux-root>' <<'PY'
from pathlib import Path
import hashlib, json, re, subprocess, sys

root = Path.cwd()
plugin = root / 'plugins/driver-porting'
prep = plugin / 'evals/enc28j60/reconstruction'
data = json.loads((prep / 'M01-INPUTS-v1.json').read_text())
count = 0
groups = [(plugin, data['repository_files']),
          (Path(sys.argv[1]), data['private_archive_files']),
          (Path(sys.argv[2]), data['retrieved_upstream_files'])]
for base, records in groups:
    for row in records:
        b = (base / row['path']).read_bytes()
        assert len(b) == row['bytes'], row['path']
        assert hashlib.sha256(b).hexdigest() == row['sha256'], row['path']
        count += 1
files = [root / 'GLOSSARY.md', plugin / 'IMPLEMENTATION-PLAN.md',
         plugin / 'evals/enc28j60/README.md', plugin / 'evidence/M01.md',
         *prep.glob('*')]
links = 0
for p in files:
    text = p.read_text()
    assert not re.search(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]', text), p.name
    assert all(line == line.rstrip() for line in text.splitlines()), p.name
    if p.suffix == '.md':
        for target in re.findall(r'\]\(([^)]+)\)', text):
            if '://' not in target and not target.startswith('#'):
                assert (p.parent / target.split('#')[0]).exists(), (p.name, target)
                links += 1
ids = ('INIT-003 REG-005 SPI-009 RX-009 RX-010 RX-001 RX-003 RX-004 RX-007 '
       'RX-005 RX-006 IRQ-006 IRQ-007 RX-012 RX-002 RX-018 TX-010 TX-011 '
       'TX-012 TX-014').split()
ledger = (plugin / 'evals/enc28j60/ledger.yaml').read_text()
assert all(re.search(r'^- id: ENC28J60-' + re.escape(rid) + r'\s*$', ledger,
                     re.MULTILINE) for rid in ids)
protected = ['evals/enc28j60/' + n for n in
             ('ledger.lock', 'ledger.yaml', 'corpus.yaml', 'SCORING-POLICY.md',
              'LEDGER-FORMAT.md', 'SCORING-FACTS.md', 'score.py', 'prepare.py',
              'ledger_check.py', 'RECONSTRUCTION-TRIAL.md')]
protected.append('skills/board-expert/scripts/strict_accept.py')
for rel in protected:
    old = subprocess.check_output(['git', '-C', str(root), 'show',
                                   '3d7eb29:plugins/driver-porting/' + rel])
    assert old == (plugin / rel).read_bytes(), rel
manifest = (prep / 'M01-PREPARATION-v1.md').read_text()
assert all(f'| B{i:02} |' in manifest for i in range(1, 10))
assert all(f'| T{i:02} ' in manifest for i in range(1, 8))
print(f'PASS: {count} pins, {links} local links, {len(ids)} ledger IDs, '
      f'{len(protected)} unchanged protected files; blocker/check inventories')
PY
```
